# Exercicios de estatistica inferencial

Pasta de pratica para testes de hipoteses.

## Notebook

| Notebook | Uso recomendado |
|---|---|
| [`01_exercicios.ipynb`](01_exercicios.ipynb) | resolver problemas de inferencia, selecionar testes e interpretar resultados |

## Checklist para cada exercicio

- identificar o tipo de variavel e o desenho amostral;
- definir hipoteses nula e alternativa;
- verificar pressupostos do teste;
- aplicar o teste adequado;
- interpretar p-valor, estatistica do teste e conclusao no contexto do problema.
