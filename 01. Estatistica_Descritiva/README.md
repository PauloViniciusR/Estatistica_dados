## Fluxo recomendado de analise

1. classificar as variaveis;
2. analisar frequencias e distribuicoes;
3. calcular medidas de tendencia central, dispersao e forma;
4. investigar outliers;
5. avaliar relacoes bivariadas;
6. so entao avancar para testes inferenciais ou modelagem.
