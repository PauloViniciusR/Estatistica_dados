## Objetivos de aprendizagem

- diferenciar estatistica descritiva e inferencial;
- identificar variaveis qualitativas e quantitativas;
- reconhecer escalas nominais, ordinais, discretas e continuas;
- preparar a base conceitual para analises exploratorias.

## Observacoes

Antes de avancar para estatistica descritiva, valide se cada variavel de um dataset esta corretamente classificada. Essa decisao influencia visualizacoes, medidas resumo, testes estatisticos e modelos.
